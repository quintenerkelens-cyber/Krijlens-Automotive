# KrijLens Automotive – iPhone PWA prototype

## Publiceren zonder kosten
1. Maak een gratis GitHub-account en een nieuwe repository (bijv. krijlens-automotive).
2. Upload alle bestanden uit deze map naar de hoofdmap.
3. Open Settings → Pages.
4. Kies Deploy from a branch, branch `main`, map `/ (root)` en Save.
5. Open de getoonde GitHub Pages-URL op je iPhone in Safari.
6. Tik op Deel → Zet op beginscherm.

## Functies
Dashboard, autovoorraad, klanten, verkoopregistratie, handtekeningen, afdrukbare verkoopakte/PDF en JSON-back-up.

## Belangrijk
Dit is een eerste prototype. Data staat lokaal in de browser en synchroniseert niet met andere apparaten. Er is geen accountbeheer, cloudback-up of versleuteling. Maak regelmatig back-ups. Test met fictieve gegevens. De verkoopakte is een concept en moet juridisch worden gecontroleerd vóór gebruik.
